## §1 引言

### §1.1 软件名称与版本

- **中文全称**：极端气候下粮食生产风险核心因子识别与韧性提升可视化决策系统
- **英文名称**：Grain Production Risk Factor Identification and Resilience Decision Support System
- **英文缩写**：GRIDSS
- **版本号**：V1.0

### §1.2 开发目的

本软件依托国家级大学生创新创业训练计划项目（N4批准版），响应国家"乡村振兴 + 粮食安全 + 气候适应"战略需求，面向省级粮食生产风险管理场景，集成多模态气候-统计-遥感数据，通过XGBoost-SHAP、基线LSTM、Attention-LSTM三模型互补归因，识别影响粮食单产的关键风险因子，并为农业管理部门、保险机构、农资企业提供可交互的情景推演与韧性路径建议。

本系统定位为**决策支持系统，模型作为引擎**。系统价值在于省内可解释归因与反事实情景模拟能力，不依赖跨省外推能力。

### §1.3 适用范围

适用于中国31个省（自治区、直辖市，不含港澳台）的粮食生产风险识别与韧性提升路径规划场景。覆盖2011年至2023年共13年的历史数据分析和当前年份的风险预测。

### §1.4 目标用户群

1. **农业管理部门**：农业农村部、省级农业厅、县级农业局——用于区域粮食安全监测与政策制定
2. **保险机构**：农险公司、再保险机构——用于农业风险评估与保费定价
3. **农资企业**：种业、化肥、农机企业——用于市场需求分析与产品规划
4. **科研机构**：农科院、高校粮食安全研究所——用于学术研究与教学演示
5. **政策研究者**：政府涉农决策参谋人员——用于政策效果模拟与评估

### §1.5 主要功能概述

本软件包含六个功能模块，通过浏览器访问，无需安装客户端：

| 模块 | 名称 | 核心功能 |
|------|------|---------|
| M00 | 系统总览 | 展示数据规模、三模型验证指标、双归因视角Top3对比，建立整体认知 |
| M01 | 风险时空地图 | 31省13年风险等级交互式地图，年份滑块切换，单省明细查询 |
| M02 | SHAP归因看板 | 11维特征边际贡献可视化，四视角（全局/农业/气候/灾害）切换 |
| M03 | 参数情景模拟 | 5维可调参数滑块，前端即时估算+后端三模型异步确认 |
| M04 | 韧性路径推荐 | 11条规则引擎生成短/中/长期三档行动建议，含预算估算 |
| M05 | 推演监控 | 实时轮询推理历史，展示近50条记录的完整输入输出 |

### §2.3 模块依赖关系

六个功能模块通过以下机制实现数据共享和交互：

1. **Pinia状态共享**（`frontend/src/stores/useProvinceStore.ts`，171行）：M01-M05共享当前选中省份、历史数据缓存和加载状态。省份选择在任一模块变更后，其他模块自动同步。

2. **RESTful API共用**：所有模块通过统一的后端API层获取数据：
   - M01调用 `GET /api/provinces?year=` 获取年份数据
   - M02调用 `GET /api/shap/<province>/<year>` 获取SHAP归因
   - M03调用 `POST /api/predict` 获取三模型预测
   - M04使用前端规则引擎（`recommendation.ts`）+ 后端 `_recommendations` 轻量版
   - M05调用 `GET /api/admin/predicts` 获取推演历史

3. **前端API封装层**（`frontend/src/api/`）：6个API模块统一管理HTTP请求，基础封装在 `http.ts`（27行），Axios实例配置baseURL、超时和拦截器。

## §3 功能描述

### §3.1 M00 系统总览

**对应源文件**：`frontend/src/views/Overview.vue`（864行）

**功能说明**：系统总览是用户进入系统的默认落点页面，以KPI卡片形式集中展示项目数据规模、三模型验证指标和双归因视角对比，帮助用户在使用各分析模块前建立对系统能力的整体认知。

**输入**：无。页面加载后自动展示静态数据。

**输出**：
- 4张KPI卡：覆盖省份（31）、数据样本（403）、三模型random 8:2 R²（XGBoost 0.907 / LSTM 0.886 / Attention-LSTM 0.816）、leave-province-out中位R²（-16.83）
- XGB-Top3因子（NDVI / 降水量 / 气温）与Attention-Top3因子（旱灾面积 / SPEI / 气温）对比区，体现双视角互补关系（Spearman ρ = -0.055）
- 数据融合进度条：省级统计100%、MODIS遥感100%、CLCD耕地掩膜60%
- 各分析模块入口卡片（M01-M05）

**技术实现**：静态页面渲染，数据从Pinia store获取。KPI卡数值为项目实测指标，不依赖后端实时请求。归因对比区强调XGB-SHAP与Attention-LSTM的方法论独立性。

### §3.2 M01 风险时空地图

**对应源文件**：`frontend/src/views/RiskMap.vue`（1144行）

**功能说明**：以中国省级交互地图呈现2011至2023年各省粮食生产风险等级的时空分布，支持年份切换和单省历史数据查询，直观把握区域风险格局演变趋势。

**输入**：
- 年份选择：通过拖动年份滑块（2011-2023）切换历史年份

**输出**：
- ECharts GeoJSON渲染的中国省级交互地图，各省按风险分位数着色（绿→黄→红五档色阶）
- 右侧省份详情面板：该省历史产量折线图 + 当年11维特征数值卡片 + 风险等级标签
- 悬停tooltip：省名、当年风险指数Y值
- Top10高风险省份排名表

**技术实现**：
- 基于ECharts中国地图GeoJSON（`frontend/public/maps/china.json`，211行）
- 调用 `GET /api/provinces?year=` 接口获取年份数据，首次请求后缓存
- 年份切换触发地图着色更新和排名表重算
- 省份点击高亮选中边界，右侧面板异步加载历史数据

### §3.3 M02 SHAP归因看板

**对应源文件**：`frontend/src/views/ShapDashboard.vue`（989行）

**功能说明**：针对用户选定省份，调用后端XGBoost-SHAP归因接口，以水平柱状图展示11维气候、致灾与管理特征各自的边际贡献方向和量级，支持四视角切换，帮助用户识别当前省份粮食风险的主控因子。

**输入**：
- 省份选择：下拉选择器（与M01/M03/M04共享Pinia状态）
- 年份选择：年份滑块
- 视角切换：全局 / 农业条件（Irr, Mech, Fert）/ 气候因子（Temp, Prec, Sun, SPEI）/ 灾害因子（Flood_R, Flood_A, Drou_A）

**输出**：
- 11维特征归一化重要性水平柱状图，按重要性降序排列
- 方向色编码：绿色=有利因子（降低风险），红色=有害因子（增加风险）
- 特征英文短码与中文名称对照标签
- Spearman秩相关提示（ρ = -0.055），说明XGB与Attention归因互补关系

**技术实现**：
- 调用后端 `GET /api/shap/<province>/<year>` 接口，返回11维归一化SHAP值
- 前端ECharts渲染水平柱状图
- 视角切换通过前端过滤特征子集实现，无需重新请求后端
- 省份切换时图表重置并重新加载

### §3.4 M03 参数情景模拟

**对应源文件**：`frontend/src/views/ScenarioSim.vue`（810行）

**功能说明**：在选定省份的基线数据基础上，提供5维关键参数可调滑块，通过前端即时估算与后端三模型异步确认的双重机制，帮助用户评估不同气候和管理干预下粮食风险的变化方向和量级。

**输入**：
- 省份选择：下拉选择器（共享状态）
- 5条参数滑块：灌溉率（Irr, %）、洪涝占比（Flood_R, %）、日照时数（Sun, h）、平均气温（Temp, °C）、SPEI干旱指数
- 每条滑块显示当前值、取值范围和调节提示方向

**输出**：
- 风险指数实时数值面板：前端公式估算值（200ms防抖即时更新）+ 后端三模型集成预测值（异步覆盖）
- ECharts雷达图：叠加展示调参前基线（虚线）与当前参数（实线）下的11维特征偏移
- 三模型集成标记：预测值旁标注模型来源

**技术实现**：
- 滑块以省份基线数据初始化，取值范围基于历史数据分布
- 前端线性公式：200ms防抖后立即更新界面估算值
- 异步调用 `POST /api/predict`，约0.5-2秒后三模型（XGBoost+LSTM+Attention-LSTM）集成结果覆盖前端估算
- 雷达图实时跟随滑块变化更新，对比基线与当前参数的11维偏移
- 重置基线按钮：一键还原所有滑块至省份原始数据

### §3.5 M04 韧性路径推荐

**对应源文件**：`frontend/src/views/ResiliencePath.vue`（987行）；规则引擎 `frontend/src/data/recommendation.ts`（338行）

**功能说明**：依据选定省份在风险指数、灌溉率、洪涝占比等关键指标上相对全国均值的偏差，由内置11条规则引擎自动生成短期、中期、长期三档行动建议卡，每张卡包含具体措施描述、优先级评级及预估介入效果，并综合计算总预算区间供规划参考。

**输入**：
- 省份选择：下拉选择器（共享状态）

**输出**：
- 左侧3项指标对比卡：风险指数Y与全国均值对比（含百分比偏差箭头）、灌溉率对比、洪涝占比对比
- 短期行动卡（约1年内）：带优先级标签的建议卡片列表
- 中期行动卡（约3年内）：带优先级标签的建议卡片列表
- 长期行动卡（约5年以上）：带优先级标签的建议卡片列表
- 底部总预算估算区间（元）

**技术实现**：
- 核心规则引擎位于 `frontend/src/data/recommendation.ts`（338行），包含11条独立规则 + `buildPathway` 合成函数
- 规则阈值基于XGB-SHAP边际贡献分位拐点 + Attention-LSTM softmax偏好，**模型驱动规则而非硬编码**
- 优先级由省份指标与全国均值的偏差幅度自动决定，偏差越大优先级越高
- 行动卡片描述文本经DOMPurify安全过滤后渲染，支持关键词高亮
- 总预算随触发规则数量动态计算
- 后端 `backend/api/predict.py::_recommendations` 提供轻量版推荐作为补充

## §4 模型集成

### §4.1 三模型互补架构

本系统的核心创新不在于追求三模型预测结果一致，而在于**诚实呈现归因分歧本身作为科学产出**。三模型分别从不同方法论视角提供互补的因子重要性判断：

**XGBoost-SHAP（横截面非线性归因）**：
- 基于梯度提升树的非线性建模，通过SHAP（SHapley Additive exPlanations）计算每个特征对单次预测的边际贡献
- 输出：全局SHAP重要性排序、局部SHAP瀑布图、交互依赖图
- 特点：捕捉特征间非线性交互，SHAP值具有博弈论可加性

**基线LSTM（时序拟合参照）**：
- 标准长短期记忆网络，对31省×13年的时间序列进行拟合
- 输出：时序预测值，作为其他两模型的精度基准参照
- 特点：纯时序建模，不显式建模特征间关系

**Attention-LSTM（内部偏好揭示）**：
- 在LSTM基础上引入softmax注意力门控机制
- 输出：注意力权重分布，揭示模型内部对不同特征的相对偏好
- 特点：与XGBoost-SHAP方法论独立，实测两者在11维特征上的Spearman秩相关系数ρ = -0.055（p = 0.873），证实双视角互补而非一致

### §4.2 推理服务架构

后端推理服务由以下核心组件构成：

**`backend/services/inference.py`（324行）**：
- 负责三模型的延迟加载（lazy load）：首次请求时加载模型到内存，后续请求复用
- 单次推理：接收11维特征向量，返回三模型各自的预测值
- 批量推理：支持批量省份数据的并发预测
- 特征预处理：Z-score标准化使用训练集统计量

**`backend/api/predict.py`（649行）**：
- `POST /api/predict` 端点：接收省份名称和可选的特征覆盖值
- 调用inference服务获取三模型独立预测
- 集成策略：三模型预测值加权平均
- 附带SHAP top-2因子归因
- 附带 `_recommendations` 韧性推荐轻量版

**模型制品存储**（`backend/models/`）：
- XGBoost: JSON格式（`xgb_model.json`）
- LSTM: Keras H5格式（`lstm_model.h5`）
- Attention-LSTM: Keras H5格式（`att_lstm_model.h5`）
- SHAP预计算结果: JSON格式（各验证协议结果）
- 双格式保障：JSON（跨平台可读）+ H5（高效推理）

### §4.3 三协议鲁棒性披露

本系统严格遵守**诚实披露**原则，在系统总览（M00）中公开三协议下的完整验证结果：

| 验证协议 | R² | 标准差 | 含义 |
|---------|-----|--------|------|
| random 8:2（论文协议） | 0.907 | ±0.038 | 省域内因子相对重要性识别，可发表口径 |
| leave-year-out | 0.894 | ±0.104 | 时序泛化能力可用，接近论文协议水平 |
| **leave-province-out 中位** | **-16.83** | — | **31省中仅1省R²>0，空间外推完全失败，诚实披露** |

leave-province-out的负R²值表明：当模型面对完全未见过的省份时，其预测能力差于简单的均值基线。这一结果是N=403样本量下31个截面单元空间外推的合理上限，**不影响系统六个模块（M00-M05）的功能输出**——系统价值定位于"省内因子相对重要性识别 + 反事实情景模拟"，不依赖跨省外推能力。

### §4.4 NDVI消融实验

为回应NDVI在SHAP排名中持续占据头条的现象，本项目实施了严格的NDVI消融实验：

- **消融方法**：从11维特征中移除NDVI，重新训练XGBoost（10维），对比R²变化
- **实验结果**：去除NDVI后R²变化 = +0.003（本质为零）
- **结论**：NDVI在SHAP边际贡献尺度上排名头条，但其对模型预测能力的实际贡献极其有限。NDVI的真实功能定位是"省域生物量代理变量"，而非模型核心驱动因子。**严禁将NDVI描述为"核心驱动"**。

- **样本量**：N = 403（31省 × 2011-2023共13年）

### §5.2 数据源

本系统整合四类异构数据源：

| 数据类别 | 关键字段 | 时间跨度 | 来源 |
|---------|---------|---------|------|
| 省级统计 | yield_kg_per_ha, Irr, Mech, Fert | 2011-2023 | 中国统计年鉴、中国农村统计年鉴、各省统计公报 |
| 气象观测 | Temp, Prec, Sun, SPEI | 2011-2023 | 中国气象数据网（CMDC） |
| 致灾因子 | Flood_R, Flood_A, Drou_A | 2011-2023 | 中国水旱灾害公报 |
| 遥感+GIS | MODIS NDVI, LST, 省级矢量, CLCD耕地像元 | 2011-2023 | NASA EARTHDATA (MODIS MOD13A3), 国家地球系统科学数据中心, 武汉大学CLCD |

所有数据均来自公开来源，不含商业秘密或个人隐私信息。

### §5.4 双层存储架构

系统采用SQLite + Parquet双层存储：

- **Parquet缓存层**：启动时从 `paper_panel_v3.parquet` 全量加载到内存，实现亚毫秒级数据访问
- **SQLite持久层**：运行时用户查询缓存、推演历史记录、省份基线数据
- **数据访问层**：`backend/services/panel_repo.py`（218行），采用Repository Pattern统一封装数据访问逻辑，上层服务不感知底层存储实现

### §5.5 数据预处理流程

1. **Z-score标准化**：所有连续特征使用训练集均值和标准差进行标准化
2. **Butterworth滤波**：对粮食单产时序进行低通滤波，去除年际高频波动
3. **时空对齐**：气象、遥感、统计、致灾四类数据按省份-年份键对齐
4. **缺失值处理**：线性插值填补单年缺失，均值填补多年连续缺失
5. **异常值检测**：基于IQR方法标记并审查极端值

**M05 推演监控**：进入页面后自动每3秒刷新。浏览推演记录表格（时间、省份、三模型预测值、时延）。点击行展开查看11维完整输入参数。关注顶部平均时延了解系统性能。

### §8.3 常见问题

**Q1：系统打开后地图不显示？**
A1：请确认浏览器支持WebGL且已允许脚本执行，使用Chrome 120或Edge 120以上版本访问。

**Q2：切换年份后数据加载缓慢？**
A2：系统首次请求该年数据时会从后端拉取并缓存，切换回已访问的年份会即时呈现。

**Q3：SHAP归因结果与情景模拟风险预测方向不一致？**
A3：两个模块基于不同模型和视角——SHAP归因使用XGBoost边际贡献，情景模拟集成三模型结果。两者互补而非要求一致，差异本身是多模型归因的科学输出（Spearman ρ = -0.055）。

**Q4：韧性路径推荐的行动建议如何理解优先级？**
A4：优先级由省份当前指标与全国均值的偏差幅度决定，偏差越大优先级越高。建议结合当地实际情况和短期、中期、长期目标统筹考量。

**Q5：推演监控中显示的响应时延异常高？**
A5：首次推理时模型需完成初始化（冷启动约20-25秒），后续推理通常在2秒以内。若持续偏高，可检查服务器资源占用情况。

### 附录C：数据库Schema（DDL）

```sql
CREATE TABLE paper_panel_v3 (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    province TEXT NOT NULL,              -- 省份名称
    year INTEGER NOT NULL,               -- 年份 (2011-2023)
    yield_kg_per_ha REAL,                -- 粮食单产 (目标变量)
    -- 11维特征
    Irr REAL,                            -- 灌溉率 (%)
    Flood_R REAL,                        -- 洪涝占比 (%)
    Sun REAL,                            -- 日照时数 (h)
    Temp REAL,                           -- 平均气温 (°C)
    SPEI REAL,                           -- 干旱指数
    Prec REAL,                           -- 降水量 (mm)
    Mech REAL,                           -- 农机总动力 (万千瓦)
    Fert REAL,                           -- 化肥施用量 (万吨)
    Drou_A REAL,                         -- 旱灾受灾面积 (千公顷)
    Flood_A REAL,                        -- 洪涝受灾面积 (千公顷)
    NDVI REAL,                           -- 植被指数 (0-1)
    -- 辅助元数据
    region_class TEXT,                   -- 区域分类
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(province, year)
);
```
