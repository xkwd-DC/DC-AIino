## §2 本次新发现：县域统计年鉴县级面板

### 2.1 位置与还原

原始包：`data/raw/statistical_yearbook_chunks/【25170】中国县域统计年鉴2000-2024.part01~23.zip`（23 分卷，2.21 GB）。

两个坑：

1. 这是**单一 zip 的切分**，直接对 part01 调 `zipfile` 会报 `File is not a zip file`，必须拼接后读取；
2. 包内中文文件名被**错误地打上 UTF-8 标志位**，解码结果是乱码且不可逆，只能按**文件大小**定位成员。

已提供可复现脚本：`scripts/data/09_extract_yearbook_county_panel.py`（虚拟拼接读取，不需落地 2.2 GB 合并文件）。

```bash
python scripts/data/09_extract_yearbook_county_panel.py
```

### 2.2 产出

| 文件 | 行 × 列 | 说明 |
|---|---|---|
| `data/raw/statistical_yearbook_extracted/county_panel_2000_2022_raw.csv` | 62,677 × 82 | 原始值，空洞多 |
| `data/raw/statistical_yearbook_extracted/county_panel_2000_2022_interpolated.csv` | 62,677 × 82 | 线性插值填补版 |

> 表内另有「回归填补(慎用)」页签，脚本默认跳过。

### 2.3 字段（82 列，摘录关键项）

主键与空间：`行政区划代码`、`年份`、`地区名称`、**`经度`、`纬度`**、`所属省份`、`所属城市`

农业相关：`农作物总播种面积(千公顷)`、`常用耕地面积(公顷)`、`机收面积(公顷)`、`设施农业占地面积(公顷)`、`农用机械总动力`、**`粮食总产量(吨)`**、`棉花产量(吨)`、`油料产量(吨)`、`肉类总产量(吨)`、`农林牧渔业总产值(万元)`、`农业增加值(万元)`、`牧业增加值(万元)`

社会经济：`年末总人口`、`乡村人口`、`乡村从业人员数`、`农林牧渔业从业人员数`、`地区生产总值`、`一二三产业增加值`、`农村居民人均可支配收入`、`地方财政一般预算收入/支出`、`全社会用电量`、`城乡居民生活用电量`、教育/卫生/文化设施等。

## §4 已确认不存在的数据（赛题五的关键缺口）

| 缺口 | 核查方式 | 影响 |
|---|---|---|
| **分作物数据**（小麦/玉米/水稻/大豆的播种面积与单产） | 扫描本机全部 xlsx/csv/parquet；县域年鉴仅到「粮食/棉花/油料/肉类」合计 | 个性化农事方案的第一个必填槽位无数据支撑 |
| **农艺知识语料**（栽培技术、生育期管理、水肥指南） | RAG 库目录 `docs/` 内 76 个文件全为项目自有文档，无农业技术资料 | 「专业性」评分项无内容 |
| **农药登记标签**（剂量、安全间隔期、登记作物） | 全盘无相关文件 | 防治建议无法合规落地 |
| **土壤属性**（质地/pH/有机质/速效养分） | 全盘无相关文件 | 水肥处方缺一半依据 |
| **实时/预报气象** | 现有气象最晚到 2024 年且为年度均值；本机无预报接口产物 | 建议与当前农时脱节 |
| **病虫害情报与图像** | 全盘无相关文件 | 病虫害模块无法演示 |
| **MODIS / CLCD 原始栅格** | 全盘无 .tif/.hdf/.nc（仅有省级聚合 parquet） | 无法重算耕地加权与物候 |
| **v5 / v6 中间面板** | `data/interim/` 无 v5/v6 parquet，仅存脚本与报告 | 报告中的 R² 无法就地复现 |
