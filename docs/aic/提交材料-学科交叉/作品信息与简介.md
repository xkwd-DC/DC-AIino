## 作品简介（≤300 字）

极端气候已成为粮食安全的核心扰动源，而农学擅长机理阐释却受统计手段限制，计算机善于建模却常脱离农学语境。本作品以四模态省级农业面板为底座，构建 31 省 × 13 年、N=403 的跨学科分析链条：XGBoost-SHAP + LSTM + Attention-LSTM 三模型互补归因，公开随机 8:2、留一年、留一省三套验证，并以混合效应方差分解校核结论来源，最终交付 7 模块 Web 决策支持系统。主报告协议 R² = 0.907 ± 0.038；留一省中位 R² = −16.83（ICC = 0.971），据此将系统定位为省内归因与情景推演，而非跨省外推预测。
