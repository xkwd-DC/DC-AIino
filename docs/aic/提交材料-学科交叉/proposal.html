一、项目概述

1. 背景与意义

学科背景。 极端气候已成为粮食安全的核心扰动源。2023 年全国平均气温创 1961 年以来新高，京津冀"23·7"极端暴雨致河北平原约 24 万公顷农田受灾，长江中下游高温干旱与西南"旱涝急转"叠加发生。在农学与农业气象学的学科视野中，这类事件提出的核心科学问题不是"某年减产多少"，而是在省级尺度上，哪些因子对粮食生产风险的边际贡献更大、方向如何、区域间是否分化——这是区域农业风险评估、种植结构调整与防灾减灾政策制定的共同前提。

学科建设意义。 长期以来，该问题的研究路径存在明显的学科割裂：农学与农业气象学擅长机理阐释但受限于统计手段，计算机科学擅长建模但常脱离农学语境。本作品以农业气象学的问题定义 + 机器学习的方法工具 + 决策科学的输出形式构建跨学科链条，为"人工智能赋能农学理论研究与科研探索"提供一条可复用的路径：把卫星观测、地面气象与统计年鉴三类异构数据在省级面板上对齐，用可解释模型输出农学可解读的因子排序，最终交付到科研与管理部门可直接使用的工具。

二、需求分析

1. 学科专业界定

本作品服务的学科领域为农学门类下的作物学与农业资源与环境（区域粮食安全风险评估方向），并交叉农业气象学与计算机科学与技术。所聚焦的核心学科环节为：

  1. 理论研究：极端气候因子的相对重要性排序及其区域分化规律；
  2. 科研探索：多源异构数据的融合建模与可解释性归因；
  3. 科研数据处理与可视化：从原始遥感/气象/统计资料到可复现分析结论的工程化流程。

切入环节之所以选"科研数据处理与可视化"，是因为它的痛点跨学科共性最强：既制约农学研究的可复现性，也制约计算机方法在农学中的落地效率。

2. 核心痛点梳理

环节现状痛点后果
数据准备四类数据源格式、时空粒度、坐标系各不相同（栅格 / 站点 / 年鉴 / 矢量），对齐工作重复且不可复用单次研究的数据准备耗时占全流程主要比例；不同研究口径不一致，结论难以横向比较
建模归因多依赖单一模型与全局重要性排序，缺乏跨原理模型的归因对照，也缺乏对模型适用边界的主动披露归因结论的稳健性无法被同行检验；易出现"把拟合能力误读为因果结论"
成果转化研究多止步于论文与离线脚本，缺少面向非技术用户的交互工具归因结论难以触达农技推广与政策制定环节

三、解决方案设计

1. 系统架构设计

系统采用"数据层 — 算法层 — 应用层"三层架构：

层次组成输出
数据层统计（产量与投入）、气象（气温/降水/日照/SPEI）、遥感（MODIS NDVI 与地表温度，按耕地像元加权）、致灾与空间（旱灾/水灾面积、省域矢量）缺失值插值 → 时空对齐 → Z-score → 403 × 27 面板

应用层REST API（推理与归因）+ Web 前端 7 模块可视化决策支持系统

2. 技术选型依据

层次选型与学科需求的适配理由
前端Vue 3 + ECharts科研人员需要"可交互探索"，而非静态图表；ECharts 地图组件适配省域展示
后端Flask 3 + gunicorn轻量、易部署到教学/科研服务器；无需 GPU
预测模型XGBoost小样本（N = 403）、中维（11 维）、非线性与交互显著，树模型是最适配的选择
归因SHAP提供样本级可加性分解，满足"农学可解读"要求（作用方向 + 单省归因 + 交互依赖）
时序对照LSTM + 特征级注意力门控省级年度面板 TIMESTEPS = 1，传统时间步注意力退化，故适配为特征级软选择门控
统计校核线性混合效应模型用方差分解定量回答"R² 究竟来自哪里"，避免过度解读
知识助手BGE-M3 嵌入 + BM25 混合检索 + 交叉编码器重排 + 大模型生成让方法论文档可直接被自然语言检索，降低科研新人上手成本

为什么强调"选型依据"而不是"越前沿越好"：N = 403 的省级面板数据规模决定了深度模型的收益上限；本项目选择用多个原理不同的轻量模型做归因对照，而非堆叠一个大模型，这与数据规模相匹配。

3. 核心技术模块

模块一：多模态时空对齐与面板数据集构建

  • 四类数据源统一到"省份 × 年度"口径；栅格遥感按省域边界聚合，且使用耕地像元权重，避免非耕地像元混入；
  • 气象站点数据按省域多站点加权平均；
  • 缺失值线性插值，全列 Z-score 标准化；
  • 产出：403 × 27 字段面板，其中 11 维入模特征 + 1 维目标（粮食单产 kg/ha）。

模块二：XGBoost-SHAP 横截面边际贡献归因

目标函数同时考虑训练损失与树结构正则项：

Obj = Σ L(y_i, ŷ_i) + Σ Ω(f_k)， ŷ_i = Σ f_k(x_i)

SHAP 将单样本预测分解为各特征贡献之和：

ŷ_i = φ_0 + Σ φ_ij

输出三个层次的归因：全局重要性（mean |SHAP|）、单样本瀑布分解、特征交互依赖。

模块三：Attention-LSTM 时序归因（特征级门控）

针对 TIMESTEPS = 1 的省级年度面板特性，将时间步注意力改造为特征级注意力门控：

e_j = vᵀ tanh(W_h x_j + b_h)

α_j = exp(e_j) / Σ_k exp(e_k)

x'_j = α_j · x_j

α 满足 Σα = 1，因此可与 SHAP 排名直接做等级相关对照——这是"互补归因"可比性的技术前提。

模块四：三协议鲁棒性披露与消融实验

协议检验目标实测（XGBoost，10 种子 / 31 折 / 13 折）
random 8:2已见省份相邻样本的拟合与省内归因能力R² = 0.907 ± 0.038，RMSE 312.5 kg/ha
leave-year-out时间外推（已见省份的未来年份）R² = 0.894 ± 0.10
leave-province-out空间外推（未见省份）中位 R² = −16.83，31 省仅 1 省 > 0

配套消融：移除 NDVI 后 R² 由 0.907 → 0.904（损失 0.003），据此拒绝"NDVI 是整体精度核心驱动"的表述；目标变量对照实验（去趋势残差目标 R² = −0.10 ± 0.28）作为方法学诚信记录一并保留。

模块五：线性混合效应校核（回答"R² 从哪来"）

用 y_it = α_i + β X_it + ε_it 做方差分解：ICC = 0.9710（95% CI [0.9496, 0.9805]），即约 97% 的总方差由省份基线差异贡献；LRT 对比混合效应与混合 OLS：LR = 741.59，p ≈ 1.35×10⁻¹⁶³。11 维固定效应中 4 项显著（机械化率、化肥投入、旱灾面积、水灾面积），NDVI 的 β 不显著（p = 0.570）。

本模块的学科价值：它把"机器学习给了一个高分"翻译成农学与统计学都能接受的结论——R² = 0.907 测的是省内因子相对重要性识别能力，不是跨省气候-产量映射能力。这一自我校核是本作品与常见"刷榜式"AI 应用最本质的区别。

（2）方法成果。 三模型互补归因架构的实证结果：

视图方法排名 Top-3
横截面边际贡献XGBoost-SHAP（mean 绝对值 SHAP）NDVI > Prec > Temp
时序内部偏好Attention-LSTM（平均 softmax attention）Drou_A > SPEI > Temp

七、总结与展望

1. 方案总结

本方案的学科贡献可归纳为三点：

  1. 把"数据对齐"这一隐性科研成本显性化、可复用化：四模态省级面板的构建流程完整记录，可被后续研究直接复用；
  2. 把"归因分歧"从缺陷转为产出：以 SHAP 与 Attention 的近零等级相关（ρ = −0.055）实证跨算法归因的方法论独立性，而非强行拼接一致性结论；
  3. 把"模型边界"写进结论：以 leave-province-out 中位 R² = −16.83 与混合效应 ICC = 0.9710 定量说明 R² = 0.907 的真实含义，使学科用户不会把拟合分数误读为跨区域预测能力。

存在的不足（如实说明）：

  • 空间粒度限于省级、N = 403，空间外推能力已确认受限，尚不能支撑"未见省份"的风险预测；
  • 时间覆盖至 2023 年，尚未纳入最新年份数据；
  • 混合效应模型中的主要投入类因子边际方向存在反向因果嫌疑（投入可能是对差年景的事后补救），纯回归框架无法识别，需后续用准实验设计处理；
  • 交互式归因看板的部分子视图（单样本瀑布、蜂群子集）依赖样本级归因接口的进一步完备。
