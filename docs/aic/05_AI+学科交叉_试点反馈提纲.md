# 学科交叉试点反馈提纲（10 分钟）

> 用途：给「应用效果」补一条真实的外部使用反馈。
> 对象：农学、农业气象、农业资源与环境等相关专业的学生或教师，1—2 人即可。
> 原则：只记录真实发生的事；没有试用就不写，不能用推测代替反馈。

## 十分钟流程

| 时间 | 动作 | 说明 |
|---|---|---|
| 0:00—0:01 | 说明来意与匿名方式 | 明确「不是考试，不需要夸，重点是找看不懂的地方」；征得同意后再记录 |
| 0:01—0:04 | 任务一：省级归因 | 让试用者自己找「某省某年主要风险因子」，观察他点哪里、卡在哪里 |
| 0:04—0:07 | 任务二：县级诊断 | 让试用者在 M07 选一个县，说出相对前一年的变化与主要因子 |
| 0:07—0:09 | 六个问题 | 按下面的提纲逐条问，不替对方总结 |
| 0:09—0:10 | 收尾与授权 | 确认能否匿名写入材料，记录日期、角色、原话 |

## 任务卡（不要先教，先让对方自己操作）

**任务一（省级）**

> 假设你要判断某省 2022 年的气候风险主要来自哪些因子，你会在系统里点哪里？请边点边说。

观察点：

- 是否先找地图、年份，还是先找 SHAP；
- 是否看得懂「带向贡献」的正负；
- 是否把「风险等级」误读成「产量绝对值」。

**任务二（县级）**

> 请在 M07 里选一个县，告诉我它 2023 年相对 2022 年是变好还是变差，主要因子是什么。

观察点：

- 是否能找到县级入口；
- 是否理解「气候异常」不是「产量」；
- 是否能读出逐年偏离轨迹与 Top 6 因子的方向。

## 六个问题

1. 你刚才想回答的问题是什么？
2. 因子方向和「气候异常」这两个概念，你看得懂吗？哪里看不懂？
3. 整个操作里，最困惑的是哪一步？
4. 如果下一次做课程作业或科研，你会不会再用一次？为什么？
5. 用一句话说一个改进建议。
6. 是否同意在匿名材料中写成「农学相关专业试用者 1 名」？是否同意引用原话？

追问只用开放句：

- 「你刚才为什么点这里？」
- 「这个词你理解成什么？」
- 「如果让你改，你先改哪一处？」

不要问：

- 「是不是很好用？」
- 「你是不是觉得这个图很清楚？」
- 「你觉得我们的模型很厉害吧？」

## 记录表

```markdown
| 字段 | 记录 |
|---|---|
| 日期 | 2026-10-__ |
| 角色 | 农学相关专业本科生 / 研究生 / 教师（不写姓名与单位） |
| 使用模块 | M02 / M07 / 两者 |
| 任务一是否完成 | 是 / 部分 / 否 |
| 任务二是否完成 | 是 / 部分 / 否 |
| 最困惑的一步 | 原话或现场观察 |
| 是否会再次使用 | 会 / 不确定 / 不会，附理由 |
| 一句话建议 | 原话 |
| 匿名引用授权 | 是 / 否 |
```

## 写进材料时的口径

可以写：

> 2026 年 10 月，1 名农学相关专业试用者用 10 分钟完成了省级归因与县级诊断两个任务；反馈指出「县级轨迹图需要先把年份口径说清楚」，该建议已记录。

不要写：

- 「用户普遍认为……」（1—2 人不能代表普遍）
- 「满意度 90%」（没有量表就不要造百分比）
- 「某教授高度评价」（没有授权就不要写身份与评价）
- 任何姓名、学校、院系、指导教师信息

## 产出位置

访谈结束后，把记录表存为：

`docs/aic/提交材料-学科交叉/试点反馈-YYYYMMDD.md`

如果只有 1 人，就如实写 1 人；如果没有人可试用，这一项留空，不用其他证据替代。
