## 录制前检查清单

1. **浏览器**：无痕窗口，隐藏书签栏，固定 1600×900 视口，缩放 100%。
2. **脱敏**：页面页脚、加载页、关于页、系统截图角标均无学校信息；录屏区域不要带桌面文件名与账号水印。
3. **系统状态**：后端服务已启动并通过模型自检（自检不通过会拒绝启动）；M01/M02/M03/M04/M05 均可正常交互。
4. **数据一致**：口播数字必须与技术方案、佐证材料一致（0.907 ± 0.038 / 0.894 ± 0.104 / −16.83 / 0.660 / ρ = −0.055）。
5. **配音**：语速平缓，术语先"说结论"再"给依据"；禁用表述——"高精度预测全国产量""预测精度达 0.9 因此可跨省推广"。
6. **导出**：MP4（H.264），1080p，时长 3—5 分钟，文件 ≤ 300 MB；导出后再看一遍全片查校名。
