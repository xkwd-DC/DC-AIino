## 一、作品概述

### 1. 背景介绍

**行业现状。** 极端气候正在改变我国粮食生产的风险结构。2023 年全国平均气温创 1961 年以来新高，京津冀"23·7"极端暴雨致河北平原约 24 万公顷农田受灾；长江中下游高温干旱、西南"旱涝急转"等事件在同一农时窗口内叠加发生。对农业生产者与管理部门而言，真正的困难不在于"是否受灾"，而在于**同一场气候冲击在不同区域的表现方向完全不同**：同样的高温在南方稻区可能意味着灌浆期热害，在北方旱作区却可能伴随有利的积温条件。

**机遇。** 与此同时，卫星遥感、地面气象观测与农业统计三类数据已经具备省级尺度的长期覆盖能力，机器学习方法也足以处理多因子非线性耦合。缺的不是数据或算法，而是**把这三类数据真正对齐、把归因结论做成农户和管理部门看得懂、用得上的形态**。

**本作品的必要性。** 现有农业气候风险服务多以"单一气候指标的阈值预警"或"黑箱预测"形式出现，前者忽略多因子耦合，后者无法解释"为什么"。本作品在这一环节投入，输出**可解释、可交互、可情景推演**的风险归因与决策支持能力。

### 2. 目标定位

| 目标 | 具体界定 | 量化指标 |
|---|---|---|
| 数据目标 | 建成统计 + 气象 + 遥感 + 致灾/空间四模态的省级农业面板数据集 | 31 省 × 13 年（2011—2023），N = 403，11 维入模特征，无缺失 |
| 预测与预警目标 | 提供省级粮食单产的风险等级评估与因子归因 | random 8:2 协议 R² = 0.907 ± 0.038，RMSE 312.5 kg/ha（10 种子均值） |
| 可解释目标 | 每个风险结论均可追溯到具体因子及其贡献方向 | SHAP 边际贡献 + Attention gating 双视角归因；单省瀑布分解 |
| 应用目标 | 交付农户与管理部门可直接使用的工具 | 7 模块 Web 系统，单次推理 < 2 秒，普通云主机可部署 |
| 边界目标 | 明确声明模型"能用在哪、不能用在哪" | 三套验证协议并行披露（含空间外推上限） |

## 二、需求分析

### 1. 问题剖析

本作品要解决的具体问题是：**在省级尺度上，把极端气候与农业生产投入的多源数据转化为可解释的风险归因与可执行的对策路径。** 从三个维度拆解其难点：

**维度一：数据维度。** 农业风险的真实驱动因素跨模态分布——气象提供致灾强度、遥感提供作物长势、统计提供投入水平、致灾公报提供实际灾情。四类数据的格式（栅格/站点/年鉴/矢量）、时空粒度与坐标系互不相同。若不做严格的时空对齐，模型学到的是数据口径差异，而非农学规律。

**维度二：方法维度。** 农业面板数据具有"小样本、强区域异质性"的典型特征。单模型、单指标的归因结论容易被误读为普适规律；而只追求拟合精度的模型，往往把**省份之间的固有单产差异**（如东北黑土区与华南丘陵区的天然差距）误当成气候因子的解释力。

**维度三：应用维度。** 一线使用者（农技推广人员、种植大户、农业保险基层机构）需要的是"我这个地区、这个阶段该做什么"，而不是一张全局重要性排序图或一个黑箱分数。

**关键难点**：如何在不牺牲方法严谨性的前提下，让归因结论**既有农学可解读性，又有明确的使用边界**。

### 2. 需求调研

本作品的选题来源于团队在农业数据方向的学习与科研实践，需求通过以下四条途径梳理：

| 途径 | 做法 | 得到的核心需求 |
|---|---|---|
| 文献研究 | 系统梳理国内外气候—粮食生产研究的方法演进与共性短板 | 需要跨模型归因对照；需要主动披露模型边界；需要从单因子走向多模态 |
| 数据实践 | 在四类公开数据源的采集与对齐过程中逐项记录口径障碍 | 需要一套可复用、可审计的数据对齐规范 |
| 场景分析 | 分析农业生产管理与保险基层机构在气候风险上的典型决策动作 | 需要"分区域、分阶段、分优先级"的对策输出，而非单一指标 |
| 用户访谈 | 面向农学方向同学与一线农技人员做需求确认〔待补·实测：访谈记录与人数〕 | 需要中文界面、地图化呈现、可调参数的推演能力 |

**归纳出的具体要求**：

1. **功能**：风险等级评估、因子归因、情景推演、对策路径四项能力缺一不可；
2. **性能**：交互响应需在秒级，否则推演过程会被打断；
3. **体验**：需为中文界面 + 地图化 + 无需安装的网页形态，适配基层使用环境；
4. **可信**：每一个结论都能点开看"依据是什么"，这是农技推广场景的刚性要求。

## 三、AI 技术工具选择与运用

本作品的 AI 技术栈按"数据处理 — 预测建模 — 归因解释 — 交互应用"四层组织，选型依据如下：

| 环节 | 技术 / 工具 | 选型依据 |
|---|---|---|
| 数据对齐 | 栅格—矢量空间聚合（含耕地像元权重）、线性插值、Z-score 标准化 | 农业数据跨模态异构，必须在入模前统一口径；耕地像元加权可避免把非耕地像元混入省级均值 |
| 风险预测 | 梯度提升树（XGBoost） | N = 403 的小样本 + 11 维中维特征 + 显著非线性与交互，树模型在该数据规模下优于深度网络；训练与推理均可在 CPU 完成 |
| 时序对照 | LSTM 与特征级注意力门控 | 农业面板以"省份 × 年度"构成，用于提供独立于树模型的第二个视角 |
| 可解释归因 | SHAP 归因框架 | 满足"每个结论可追溯"的刚性需求：全局重要性、单样本贡献分解、特征交互依赖三种解释粒度 |
| 统计校核 | 线性混合效应模型（方差分解） | 定量分离"省份固有差异"与"因子边际效应"，避免把区域基线误读为气候解释力 |
| 边界验证 | 三协议交叉验证 + 消融实验 | 主动量化模型在时间外推与空间外推两类场景下的能力差异 |
| 应用交付 | Vue 3 + ECharts 前端；Flask 后端；CPU 深度学习框架与梯度提升库 | 轻量、可部署在普通云主机、无 GPU 依赖，适配基层使用条件 |
| 知识服务 | 中文多模态嵌入模型 + BM25 混合检索与重排 + 大模型生成 | 把方法论文档变成可自然语言检索的知识库，降低基层使用者的理解门槛 |

> **技术选型的一个关键判断**：本作品刻意**没有**选择"堆叠更大的模型"。原因是在 N = 403 的省级面板上，更大的模型只会更充分地记住 31 个省份的基线差异（后文混合效应校核对此给出了定量证据：省份基线解释了约 97% 的总方差），而不会带来可迁移的气候—产量知识。**把算力投入"归因对照与边界验证"，而不是"刷高拟合分数"，是本作品技术路线上的核心选择。**

## 四、项目实施

### 1. 实施方案设计

| 阶段 | 主要工作 | 时间安排 | 资源与分工 |
|---|---|---|---|
| 一 · 数据底座 | 四类数据源采集；栅格按省域 + 耕地像元加权聚合；气象站点加权平均；缺失值插值与标准化 | 起始阶段，约 1/4 周期 | 数据负责人主责；算法负责人复核口径 |
| 二 · 预测建模 | XGBoost / LSTM / Attention-LSTM 三模型训练；超参与种子记录 | 约 1/4 周期 | 算法负责人主责 |
| 三 · 归因与校核 | SHAP 全量归因、注意力权重提取、混合效应方差分解 | 与阶段二交叠 | 算法负责人主责；数据负责人复核 |
| 四 · 边界验证 | random 8:2 / leave-year-out / leave-province-out 三协议；NDVI 消融 | 约 1/8 周期 | 算法负责人主责 |
| 五 · 系统开发 | API 化封装；前端 7 模块；安全与无障碍加固；部署上线 | 约 1/4 周期 | 系统负责人主责；文档负责人配合 |
| 六 · 验证固化 | 真值单点校验、响应时延实测、文档与操作手册齐备 | 收尾 | 全员 |

### 2. 关键技术实现 / AI 工具运用

**（1）多源农业数据的时空对齐。** 四类数据统一到"省份 × 年度"口径。栅格遥感（NDVI、地表温度）按省域行政边界聚合，并进一步以**耕地像元权重**加权，确保省均值反映的是耕地上的作物状态而非全省平均状态；气象站点数据按省域多站点加权平均；统计与致灾数据按年鉴口径直接取用。缺失值线性插值，全列 Z-score 标准化。

**（2）机理—数据耦合的指标体系。** 11 维特征并非纯数据驱动筛选，而是按"气象致灾（气温、降水、日照、标准化降水蒸散指数 SPEI）— 遥感长势（NDVI、地表温度）— 生产投入（灌溉率、机械化率、化肥施用量）— 实际灾情（旱灾面积、水灾面积）"的农学因果链条组织。其中 SPEI 本身是**机理型干旱指标**（基于降水与蒸散差的标准化），将其与数据驱动模型结合，是"机理—数据耦合"的具体落地。

**（3）三模型互补归因架构。** 三个原理完全不同的模型各自承担不同任务，而非追求结论一致：

| 模型 | 承担任务 | 回答的问题 |
|---|---|---|
| XGBoost-SHAP | 横截面边际贡献归因 | 去掉某因子，预测误差会变化多少 |
| LSTM（基线） | 时序拟合参照 | 作为注意力模型的同源对照基线 |
| Attention-LSTM | 内部 gating 偏好揭示 | 模型主动把权重分配给哪些因子 |

针对省级年度面板时间步退化为 1 的情况，将常规时间步注意力改造为**特征级注意力门控**：

    e_j = vᵀ tanh(W_h x_j + b_h)
    α_j = exp(e_j) / Σ_k exp(e_k)
    x'_j = α_j · x_j

α 满足归一化约束，因此可直接与 SHAP 排名做等级相关对照。

**（4）边界验证与负结果披露。**

| 验证协议 | 检验场景 | 实测结果（XGBoost） |
|---|---|---|
| random 8:2（10 种子） | 已见省份相邻样本 | R² = 0.907 ± 0.038；RMSE = 312.5 kg/ha |
| leave-year-out（13 折） | 时间外推 | R² = 0.894 ± 0.10 |
| leave-province-out（31 折） | 空间外推 | 中位 R² = −16.83，31 省仅 1 省 > 0 |

配套消融实验：移除 NDVI 后 R² 由 0.907 降至 0.904，**边际贡献仅 0.003**，据此主动修正"植被指数是核心驱动因子"的直觉判断。

**（5）方差分解校核（回答"高分从哪来"）。** 以 y_it = α_i + β X_it + ε_it 分解总方差，得到 **ICC = 0.9710**（95% 置信区间 [0.9496, 0.9805]），即约 **97% 的总方差来自省份之间的固有单产差异**，而非气候因子的边际效应。似然比检验对比混合效应与混合 OLS：LR = 741.59（p 远小于 0.001），确证省份基线不可忽略。11 维固定效应中 4 项在 5% 水平显著，NDVI 项不显著（p = 0.570）。

> **这一步是本作品诚实性的核心体现**：它把"R² = 0.907"从一句可能被误读的成绩，翻译成一句准确的结论——**该分数衡量的是省内因子相对重要性识别能力，而不是跨省的气候—产量映射能力**。基于这一结论，系统的定位被明确为"对已覆盖省份提供可解释的风险归因与情景推演"，而非"预测任意省份的产量"。

**（6）系统实现。** 前端 Vue 3 + ECharts，后端 Flask；7 个功能模块：系统总览（M00）、风险时空地图（M01）、归因看板（M02）、参数情景模拟（M03）、韧性路径推荐（M04）、推演监控（M05）、知识助手（M06）。其中韧性路径推荐由 **12 条白箱规则**构成，触发阈值源自模型归因结果的分位拐点，输出按 0-1 年 / 1-3 年 / 3-5 年三阶段组织，全过程可审计、可调参。

## 五、应用成效

### 1. 成果展示

**（1）数据成果。** 建成 31 省 × 13 年（2011—2023）× 11 维特征的多模态农业面板数据集（N = 403），涵盖气象致灾、遥感长势、生产投入与实际灾情四类变量，配套逐字段的来源说明与处理口径文档，可直接被后续研究复用。

**（2）模型与归因成果。**

| 视图 | 方法 | Top-3 因子 |
|---|---|---|
| 横截面边际贡献 | XGBoost-SHAP | NDVI > 降水 > 气温 |
| 时序内部偏好 | Attention-LSTM | 旱灾面积 > SPEI > 气温 |

两套排名的 Spearman 等级相关 ρ = **−0.055（p = 0.873）**，Top-3 仅"气温"一项重合。

**这一结果对农业应用有直接含义**：若只看 SHAP，会得到"植被指数最重要"的结论；若只看注意力权重，会得到"旱灾面积最重要"的结论。二者的近零相关说明——**单一归因方法不足以支撑政策结论**。因此本作品的韧性路径推荐并未采用单一模型的排序，而是让两套视角并列进入加权排序，冲突时按各自权重竞争而非相互否决。

**（3）系统成果。** 7 模块 Web 决策支持系统，具备风险时空地图（31 省 × 13 年时间轴）、单省归因分解、参数情景模拟（调整灌溉率/化肥/降水等因子实时反馈）、三阶段韧性路径输出、推演过程监控与知识问答能力。

**（4）实测指标。**

| 指标 | 实测值 |
|---|---|
| 单次推理响应时间 | < 2 秒 |
| 主报告协议预测精度 | R² = 0.907 ± 0.038（10 种子），RMSE = 312.5 kg/ha |
| 时间外推表现 | R² = 0.894 ± 0.10（leave-year-out） |
| 空间外推表现 | 中位 R² = −16.83（leave-province-out，31 省仅 1 省 > 0） |
| 单点真值校验（某主产省某年，实际单产 4615 kg/ha） | XGBoost 偏 −227.5；LSTM 偏 −441.6；Attention-LSTM 偏 +42.6 |
| 无障碍规范 | 满足 WCAG 2.2 AA |
| 系统安全 | 6 项安全响应头 + 请求限流 |

### 2. 效益分析

**（1）经济效益。** 本作品对农业生产的经济价值体现为**降低决策试错成本**：

- 情景模拟模块可在不实际调整生产的前提下，定量推演"灌溉率提高 / 化肥投入变化 / 降水增减"对区域单产风险的影响方向与量级，为投入决策提供前置参考；
- 数据与系统的边际复制成本极低：新增省份或作物只需补充数据重新训练，系统无需改造，具备规模推广的经济可行性；
- 对农业保险基层机构而言，可解释的分省风险归因可作为差异化产品设计与费率复核的参考依据。

> 具体的成本—收益测算需结合试点单位数据，当前以定性论证为主〔待补·实测〕。

**（2）社会效益。**

- **服务粮食安全**：为区域农业管理部门提供极端气候情境下的风险识别与因子归因工具，支撑防灾减灾资源的精准投放；
- **降低技术门槛**：全中文网页形态、无需安装、无需 GPU 服务器，适配基层使用环境；知识助手（M06）让不具备建模背景的使用者也能检索方法细节；
- **推动结论规范使用**：通过主动披露空间外推上限（中位 R² = −16.83），避免"AI 预测全国产量"式的过度宣传，这是对农业 AI 应用生态的正向贡献。

**（3）学科建设与科研效益。**

- **方法可迁移**：三模型互补归因 + 多协议披露的框架与具体作物无关，可迁移至其他"气候—生产"研究议题；
- **流程可复用**：四模态数据对齐与耕地像元加权聚合流程可复用于同类省级面板研究；
- **教学可用**：交互式归因看板与情景模拟适合作为农学、农业气象、数据科学相关课程的实训模块；
- **结论可检验**：全部超参、随机种子与模型卡片齐备，结论可被独立复现。

## 六、总结与展望

### 1. 经验总结

**成功经验：**

1. **痛点定位决定了作品价值**：本作品没有从"用最新模型"出发，而是从"同一气候冲击在不同区域方向相反"这一农业真实痛点出发，因此归因能力比预测精度更有价值；
2. **把负结果当作产出**：空间外推失败（中位 R² = −16.83）与 NDVI 边际贡献接近零（ΔR² = 0.003）两项负结果，反而构成了作品最有说服力的部分——它们让模型的使用边界变得清晰，也让系统的定位不易被质疑穿透；
3. **可解释性是农业场景的刚需**：SHAP 双视角对照与白箱规则引擎的设计，直接对应"基层使用者需要知道依据"这一调研结论。

**不足之处：**

- 空间粒度限于省级，尚不能支撑县级或地块级建议；
- 时间覆盖至 2023 年，未纳入最新年份；
- 需求调研的样本量与访谈记录仍需补充规范化（当前部分依赖团队学习与科研实践中的观察）；
- 生产投入类因子的边际方向存在反向因果嫌疑（投入可能是对差年景的事后补救），回归框架无法识别；
- 尚缺来自生产一线的规模化使用反馈。

### 2. 未来规划

| 阶段 | 规划 | 目标 |
|---|---|---|
| 近期 | 补充需求调研与试点反馈；完善样本级归因接口 | 把"效果验证依据"从团队内部实测扩展为外部佐证 |
| 中期 | 空间粒度由省级下移至县域；纳入新年份数据 | 提高省内变异占比，使气候—产量关系具备可辨识性；形成滚动更新机制 |
| 中期 | 引入随机斜率等结构检验区域异质性；尝试准实验设计处理反向因果 | 从"相关归因"走向"因果归因"，支撑更硬的政策建议 |
| 远期 | 与农技推广、农业保险等场景对接，形成"风险识别—归因—对策—效果回访"闭环 | 建立可复制、可推广的农业气候风险服务模式 |

**产业推广策略：**

1. **由点及面**：先在 1-2 个主产省做深度试点，形成可展示的应用案例，再横向复制；
2. **轻量化交付**：坚持无需 GPU、单体部署的技术路线，降低基层单位的落地门槛；
3. **开放数据与接口**：数据集说明与 API 接口对外开放，吸引同类研究复用，形成方法层面的行业共识；
4. **规范先行**：在推广中坚持"边界清晰"的表达方式，把诚实的适用边界作为产品的可信度资产而非短板。
