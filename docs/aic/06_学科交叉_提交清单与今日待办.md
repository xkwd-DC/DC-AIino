## §3 重新生成材料的命令（需要时使用）

```powershell
# 1) Markdown 底稿 -> HTML（列宽自动推断；封面取自 cover_cross.json）
python scripts/aic/md2proposal.py "docs/aic/01_AI+学科交叉_技术方案_匿名版.md" `
  "docs/aic/提交材料-学科交叉/proposal.html" `
  --cover scripts/aic/cover_cross.json --template "docs/aic/提交材料-赛题二/proposal.html"

# 2) HTML -> DOCX
python scripts/aic/html2docx.py "docs/aic/提交材料-学科交叉/proposal.html" `
  "docs/aic/提交材料-学科交叉/禾衡-粮食生产气候风险归因决策系统-技术方案.docx"

# 3) DOCX -> PDF（WPS COM，格式码 17）
#    见 scripts/aic/README.md 的两行 COM 调用

# 4) 答辩材料（WPS Presentation COM，按页导出 PNG 便于检查）
pwsh -NoProfile -ExecutionPolicy Bypass -File scripts/aic/build_deck_track2.ps1 `
  -DataJson scripts/aic/deck_data_cross.json

# 5) 图件重绘（架构图与三协议图）
python scripts/aic/make_figs_cross.py "docs/aic/提交材料-学科交叉/img"

# 6) 推理耗时实测（模型侧，5 次均值；结果用于技术方案与佐证材料的实测表）
python scripts/aic/bench_inference.py --runs 5
```

> 注意：材料脚本必须在 **PowerShell 7（pwsh）** 下运行；Windows PowerShell 5.1 会按 ANSI 解析 UTF-8 脚本而报语法错误。
