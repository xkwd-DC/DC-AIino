一、作品概述

1.1 背景介绍

行业现状。极端气候正在改变我国粮食生产的风险结构。2023 年全国平均气温创 1961 年以来新高；京津冀"23·7"极端暴雨致河北平原约 24 万公顷农田受灾；长江中下游高温干旱与西南"旱涝急转"等事件在同一农时窗口内叠加发生。对农业生产者与管理部门而言，真正的困难不在于"是否受灾"，而在于同一场气候冲击在不同区域的表现方向完全不同：同样的高温在南方稻区可能意味着灌浆期热害，在北方旱作区却可能伴随有利的积温条件。以单一气候指标的阈值做预警，或只给出一个黑箱分数，都无法支撑"哪里该优先防、防什么、先做什么"的决策。

数据与算法机遇。卫星遥感、地面气象观测与农业统计三类数据已经具备省级尺度的长期覆盖能力，机器学习方法也足以处理多因子非线性耦合。真正的缺口不在数据源或算法库，而在于三件事：其一，把格式、时空粒度与坐标系各不相同的多模态数据严格对齐，使模型学到的是农学规律而不是数据口径差异；其二，让归因结论具备可解释性，能够回答"为什么是这些因子"；其三，主动界定模型适用边界，避免结论被误用。

本作品的必要性。现有农业气候风险服务多集中在两个极端：一端是"单一气候指标阈值预警"，忽略多因子耦合，难以区分风险的具体来源；另一端是"黑箱预测"，精度看似很高却无法解释，一旦被追问依据便无法自证。本作品在两者之间投入，构建一套可解释、可交互、可情景推演的风险归因与决策支持系统，把预测能力转化为可追溯、可核查的决策依据。

二、需求分析

2.1 问题剖析

本作品要解决的具体问题是：在省级尺度上，把极端气候与农业生产投入的多源数据转化为可解释的风险归因与可执行的对策路径。从三个维度拆解其难点。

维度一：数据维度。农业风险的真实驱动因素跨模态分布——气象提供致灾强度、遥感提供作物长势、统计提供投入水平、致灾公报提供实际灾情。四类数据的格式（栅格 / 站点 / 年鉴 / 矢量）、时空粒度与坐标系互不相同。若不做严格的时空对齐，模型学到的是数据口径差异，而非农学规律。举例而言，若直接对省域内全部栅格取平均，山区林地像元会把耕地上的长势信号稀释，得到的"省均植被指数"与实际作物长势并不对应。

维度二：方法维度。农业面板数据具有"小样本、强区域异质性"的典型特征。N = 403 的样本规模下，模型容量越大，越容易记住 31 个省份的基线差异；单模型、单指标的归因结论则容易被误读为普适规律。突出表现为一种常见陷阱：把省份之间的固有单产差异（如东北黑土区与华南丘陵区的天然差距）误当成气候因子的解释力，从而得出"某气候因子对全国产量贡献最大"的似是而非结论。

维度三：应用维度。一线使用者（农技推广人员、种植大户、农业保险基层机构）需要的是"我这个地区、这个阶段该做什么"，而不是一张全局重要性排序图或一个黑箱分数。这意味着系统的输出必须落到区域、阶段与优先级，并且每一条结论都能点开看依据。

关键难点：如何在不牺牲方法严谨性的前提下，让归因结论既有农学可解读性，又有明确的使用边界。

技术选型的一个关键判断：本作品刻意没有选择"堆叠更大的模型"。原因是在 N = 403 的省级面板上，更大的模型只会更充分地记住 31 个省份的基线差异，而不会带来可迁移的气候—产量知识。后文混合效应校核对此给出了定量证据：省份基线解释了约 97% 的总方差。因此本作品把算力投入"归因对照与边界验证"，而不是"刷高拟合分数"。

4.2 关键技术实现

（1）多源农业数据的时空对齐

四类数据统一到"省份 × 年度"口径。栅格遥感（植被指数、地表温度）按省域行政边界聚合，并进一步以耕地像元权重加权，确保省均值反映的是耕地上的作物状态而非全省平均状态；气象站点数据按省域多站点加权平均；统计与致灾数据按年鉴口径直接取用。缺失值采用线性插值，全列 Z-score 标准化，标准化器与模型文件一并留档，保证线上推理与离线评估口径一致。

（2）机理—数据耦合的指标体系

11 维特征并非纯数据驱动筛选，而是按"气象致灾（气温、降水、日照、标准化降水蒸散指数 SPEI）— 遥感长势（植被指数、地表温度）— 生产投入（灌溉率、机械化率、化肥施用量）— 实际灾情（旱灾面积、水灾面积）"的农学因果链条组织。其中 SPEI 本身是机理型干旱指标（基于降水与蒸散差的标准化），将其与数据驱动模型结合，是"机理—数据耦合"的具体落地：模型不必从零学习干旱的物理含义，只需学习干旱强度与产量偏离之间的区域化映射。

（3）三模型互补归因架构

三个原理完全不同的模型各自承担不同任务，而非追求结论一致。

表 5　三模型的角色分工
模型承担任务回答的问题
XGBoost-SHAP横截面边际贡献归因去掉某因子，预测误差会变化多少
LSTM（基线）时序拟合参照作为注意力模型的同源对照基线
Attention-LSTM内部 gating 偏好揭示模型主动把权重分配给哪些因子

针对省级年度面板时间步退化为 1 的情况，将常规时间步注意力改造为特征级注意力门控：

ej = vT tanh(Whxj + bh)　　αj = exp(ej) / Σkexp(ek)　　x′j = αj · xj

α 满足归一化约束，因此可直接与 SHAP 排名做等级相关对照，形成"外部边际贡献"与"内部权重偏好"两个独立视角。

配套消融实验：移除植被指数后 R² 由 0.907 降至 0.904，边际贡献仅 0.003，据此主动修正"植被指数是核心驱动因子"的直觉判断——该特征在本数据集中的边际信息已被其他变量覆盖。

（5）方差分解校核：回答"高分从哪来"

以 yit = αi + βXit + εit 分解总方差，得到 ICC = 0.9710（95% 置信区间 [0.9496, 0.9805]），即约 97% 的总方差来自省份之间的固有单产差异，而非气候因子的边际效应。似然比检验对比混合效应模型与混合 OLS：LR = 741.59（p 远小于 0.001），确证省份基线不可忽略。11 维固定效应中 4 项在 5% 水平显著，植被指数项不显著（p = 0.570）。

这一步是本作品结论口径的核心：它把"R² = 0.907"从一句可能被误读的成绩，翻译成一句准确的结论——该分数衡量的是省内因子相对重要性识别能力，而不是跨省的气候—产量映射能力。由此，系统的定位被明确为"对已覆盖省份提供可解释的风险归因与情景推演"，并在界面上对超出该范围的询问主动说明边界。

（6）系统实现

前端 Vue 3 + ECharts，后端 Flask，全部模块由统一 API 对外服务。系统包含 7 个功能模块：系统总览（M00）、风险时空地图（M01）、归因看板（M02）、参数情景模拟（M03）、韧性路径推荐（M04）、推演监控（M05）、知识助手（M06）。其中韧性路径推荐由 12 条白箱规则构成，触发阈值源自模型归因结果的分位拐点，输出按 0—1 年 / 1—3 年 / 3—5 年三阶段组织，全过程可审计、可调参，不使用不可解释的隐式打分。

五、应用成效

5.1 成果展示

（1）数据成果

建成 31 省 × 13 年（2011—2023）× 11 维特征的多模态农业面板数据集（N = 403），涵盖气象致灾、遥感长势、生产投入与实际灾情四类变量；在此基础上扩展出城市级（148 个地级市 × 13 年）、县级建模（1 041 县 × 11 年）与县级社会经济（2 725 县 × 23 年，62 676 条记录）三套面板，用于空间尺度递进验证与县域查询。全部数据集配套逐字段的来源说明、单位、时空口径与质量审计结论，可直接被后续研究复用。

5.2 效益分析

（1）经济效益

本作品对农业生产的经济价值体现为降低决策试错成本：

  • 情景模拟模块可在不实际调整生产的前提下，定量推演"灌溉率提高 / 化肥投入变化 / 降水增减"对区域单产风险的影响方向与量级，为投入决策提供前置参考；
  • 数据与系统的边际复制成本极低：新增省份只需补充数据重新训练，系统无需改造，具备规模推广的经济可行性；
  • 对农业保险基层机构而言，可解释的分省风险归因可作为差异化产品设计与费率复核的参考依据。

需要说明的是，成本—收益的定量测算需结合试点单位的实际投入与赔付数据，现阶段以定性论证为主；作品不作脱离数据的收益承诺。

（2）社会效益

  • 服务粮食安全：为区域农业管理部门提供极端气候情境下的风险识别与因子归因工具，支撑防灾减灾资源的精准投放；
  • 降低技术门槛：全中文网页形态、无需安装、无需 GPU 服务器，适配基层使用环境；知识助手（M06）让不具备建模背景的使用者也能检索方法细节与数据口径；
  • 推动结论规范使用：通过主动披露空间外推上限（中位 R² = −16.83），避免"AI 预测全国产量"式的过度宣传，这是对农业 AI 应用生态的正向贡献。

（3）学科建设与科研效益

  • 方法可迁移：三模型互补归因 + 多协议披露的框架与具体作物无关，可迁移至其他"气候—生产"研究议题；
  • 流程可复用：四模态数据对齐与耕地像元加权聚合流程可复用于同类省级面板研究；
  • 教学可用：交互式归因看板与情景模拟适合作为农学、农业气象、数据科学相关课程的实训模块；
  • 结论可检验：全部超参、随机种子与模型卡片齐备，结论可被独立复现。

六、总结与展望

6.1 经验总结

成功经验：

  1. 痛点定位决定了作品价值。本作品没有从"用最新模型"出发，而是从"同一气候冲击在不同区域方向相反"这一农业真实痛点出发，因此归因能力比预测精度更有价值；
  2. 把负结果当作产出。空间外推失败（中位 R² = −16.83）与植被指数边际贡献接近零（ΔR² = 0.003）两项负结果，反而构成了作品最有说服力的部分——它们让模型的使用边界变得清晰，也让系统的定位不易被质疑穿透；
  3. 可解释性是农业场景的刚需。SHAP 双视角对照与白箱规则引擎的设计，直接对应"基层使用者需要知道依据"这一调研结论。

不足之处：

  • 空间粒度以省级为主，县域层面虽有面板与验证结果，但尚未形成逐县的地块级建议；
  • 时间覆盖至 2023 年，未纳入最新年份数据；
  • 需求调研以文献、数据实践与场景分析为主，一线访谈记录仍有待规模化补充；
  • 生产投入类因子的边际方向存在反向因果嫌疑（投入可能是对差年景的事后补救），当前回归框架无法识别；
  • 尚缺来自生产一线的规模化使用反馈。

  1. 由点及面：先在 1—2 个主产省做深度试点，形成可展示的应用案例，再横向复制；

  3. 开放数据与接口：数据集说明与 API 接口对外开放，吸引同类研究复用，形成方法层面的行业共识；
  4. 规范先行：在推广中坚持"边界清晰"的表达方式，把诚实的适用边界作为产品的可信度资产。
