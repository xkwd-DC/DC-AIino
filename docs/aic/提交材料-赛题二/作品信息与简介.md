## 参赛赛题

## 作品简介（≤300 字）

极端气候已成为粮食安全的核心扰动源，而现有服务多为单指标阈值或难以解释的黑箱分数。本作品构建 31 省 × 13 年、N=403 的四模态省级农业面板，提出 XGBoost-SHAP + LSTM + Attention-LSTM 三模型互补归因架构，公开随机 8:2、留一年、留一省三套验证，并交付 7 模块 Web 决策支持系统，单次推理秒级完成、无 GPU 依赖。主报告协议 XGBoost R² = 0.907 ± 0.038（RMSE 312.5 kg/ha）；严格留一省协议中位 R² = −16.83，据此定位为省内归因与情景推演，而非跨省外推预测。
