# Design System — 极端气候下粮食生产风险智能分析（DC / 稷韧云图）

## Overview

一块深墨绿的科研仪表盘。整站底色是接近黑色的森林绿，内容被一层层 1px 描边的卡片切成方格，像农业遥感卫星的夜视控制台而不是常见的白底管理系统。视觉重心永远在数据上：大号等宽数字、黄绿到赭石的风险色阶、细到几乎看不见的分隔线。中文字体走 Noto Serif SC 做标题、Noto Sans SC 做正文、JetBrains Mono 做所有编号与数值标签，形成"论文 + 仪器"的双重语气。整体不发光、不炫技，靠密度和对比度说话。

## Colors

- **Primary Surface（底色）**: `#162520` — 全站深墨绿背景
- **Surface Raised（卡面）**: `#283A35` — 数据卡、面板底色
- **Surface Sunken（内嵌区）**: `#1F2F2A` — 图表画布、次级区块
- **Surface Elevated（高亮卡）**: `#324942` — hover / 选中态
- **Primary Content（正文）**: `#E8E4D8` — 米白，标题与主数值
- **Secondary Content（次级文字）**: `#A8B5AC` — 说明文案
- **Tertiary Content（标签）**: `#95A39B` — 元信息、脚注（已达 WCAG AA）
- **Accent Green（主强调）**: `#A0B785` — 品牌绿，指标条、正常态
- **Accent Green Bright（亮强调）**: `#C5D4AF` — 数值高亮、可交互文字
- **Risk Ramp（风险色阶）**: `#F2DDB8` → `#E6B655` → `#C68552` → `#A56548` → `#7E4530`（低→高风险）
- **Alert / Down**: `#B86F4D`（赭石，风险上升、负向贡献）、`#D8916F`（亮赭石）
- **Info**: `#6BA8B5`（图表第三色系，用于 LSTM 相关指标）

## Typography

- **Serif**: `Noto Serif SC`（400/500/600/700）。页面标题、模块名、"核心云图 · 系统总览"。中式学术气，笔画收得住。
- **Sans**: `Noto Sans SC`（300/400/500/600/700）。正文、说明、按钮。字号小（12–15px），行高 1.7。
- **Mono**: `JetBrains Mono`（400/500/600）。所有编号（M00–M06）、英文小标（COVERAGE / TRI-MODEL R²）、数值（0.907 / −16.83 / 2825 ms）。高字距、全大写、10–13px。
- **层级**: 模块标题 28px / 卡片标题 16px / 数值 32–64px 等宽 / 正文 14px / 标签 10–11px。

## Elevation

不用阴影。深度全部靠 1px 描边（`#2A3D38`，强描边 `#44615A`）加底色层级递进：`#162520` → `#1F2F2A` → `#283A35` → `#324942`。圆角极小（3–8px），近乎方正的仪器面板感。顶栏是唯一使用毛玻璃的地方：`rgba(22,37,32,.88)` + `backdrop-filter: blur(16px)`。全局另有两处极淡的径向光斑（绿色 4%、琥珀 3%）避免大面死黑。

## Components

- **Module Tabs（模块导航条）**: 顶栏横向 tab，`M01 风险时空地图` 双行结构——等宽编号在上、中文名在下；选中态是 `#324942` 填充 + `#44615A` 描边。
- **Brand Lockup**: 34px 方形渐变绿徽标（内嵌"粮"字）+ 主标题 + `FOOD-RISK INTELLIGENCE PLATFORM` 等宽副标。
- **Stat Card（指标卡）**: 顶端 2px 彩色标线（绿/琥珀/赭石区分语义），等宽大写小标 + 中文说明 + 超大数值 + 一行脚注。
- **Choropleth Risk Map**: 中国省界填色地图 + 底部 2011–2023 年份 scrubber，高风险省份由赭石压到深红褐。
- **Risk Ramp Legend**: 连续渐变色带，两端标最小/最大值，用于解释地图配色。
- **Top-10 Rank Bars**: 编号 + 省份名 + 横向条形 + 等宽数值，行间用 1px 分隔线。
- **Gauge Dial（仪表盘）**: 半圆刻度盘，指针 + 中心大数值，用于基线风险 vs 模拟风险对比。
- **Parameter Sliders**: 五行滑块，左侧图标 + 名称 + 等宽现值，右侧区间标注"越高风险越低/越高"。
- **Waterfall / Marginal Contribution Bars**: 每个因子的边际贡献条形，绿色为降低风险、赭石为抬升风险，零轴居中。
- **Inference Trace Table**: 等宽表格，时间 / 省份 / 模型 / 风险 / 共识 / 分歧 / 响应时长，配 chip 形式的模型标签。
- **Stage Timeline（M04）**: 短期应急 / 中期建设 / 长期布局三段式竖轴，节点圆点 + 编号条目。
- **Assistant Composer**: 知识助手空态，居中图标 + 建议提问胶囊 + 底部输入框。

## Do's and Don'ts

### Do's

- 用 1px `#2A3D38` 描边切分区块，而不是用底色分层级
- 数字一律等宽字体 + `font-variant-numeric: tabular-nums`，小数点对齐
- 绿=安全/提升，琥珀=中风险，赭石=高风险/下降，颜色只承担语义
- 中文标题留出 0.3–0.4px 字距，小标签用等宽字体并加宽字距
- 让留白出现在卡片内部，卡片之间保持 20–24px 的固定节奏

### Don'ts

- 不要在白底上做这个视频——品牌身份是深墨绿底
- 不要加投影、发光或玻璃拟态（顶栏除外），层级靠描边
- 不要把强调绿 `#A0B785` 铺满大面积色块，它只做线与字
- 不要用圆润的胶囊按钮或大圆角卡片，圆角上限 8px
- 不要使用满屏线性渐变，会在大面积暗部产生 H.264 色带
